# Triage labels

Default canonical triage labels (setup-matt-pocock-skills), as used by the local markdown tracker at `Second Cerveau/1 PROJETS/tightcode/TICKETS/`:

| Label | Meaning |
|---|---|
| `needs-triage` | newly published, not yet examined |
| `needs-info` | blocked, waiting on information |
| `ready-for-agent` | examined, agent-grabbable |
| `ready-for-human` | examined, human decision required |
| `wontfix` | examined, explicitly not doing |

Tickets carry a `Status:` line near the top; transition it as the ticket moves through the states.
