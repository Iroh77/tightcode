# Domain docs

Domain vocabulary and decision records live in the **vault** (the source of truth), reachable from the repo via the `Second Cerveau` symlink:

- **Glossary** (domain vocabulary): `Second Cerveau/1 PROJETS/tightcode/REQUIREMENTS/glossary.md`
- **Decision records / ADRs** (the "why" of requirements and design): `Second Cerveau/1 PROJETS/tightcode/REQUIREMENTS/decisions/R<NN>-<seq>.md` (per requirement) + `Second Cerveau/1 PROJETS/tightcode/ARCHITECTURE/decisions/<feature>-<seq>.md` / `basic-design-<seq>.md` (per design decision)
- **Shared cross-feature contracts**: `Second Cerveau/1 PROJETS/tightcode/ARCHITECTURE/detailed/_shared.md`

Read via `Second Cerveau/1 PROJETS/tightcode/…` — never the absolute machine path.
