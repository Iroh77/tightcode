Execute a deferred tool that is not listed in the tool listing.

Deferred tools are discovered through the <deferred_tools> catalog blocks in the
system prompt, which list each tool's name and a short description. Call
load_tool with a tool's name first to receive its full input schema — do not
guess the argument shape from the short catalog summary.

To execute a loaded deferred tool, pass its exact catalog name as `name` and its
arguments object serialized to a JSON string as `args`. The `args` value is a
JSON string, so inner quotes are escaped.

Example — after loading `glob` via load_tool, a call to glob(pattern) becomes:

{"name": "glob", "args": "{\"pattern\": \"src/**/*.ts\"}"}

Tools that do appear in the tool listing must be called directly — this tool is
only for deferred ones.
